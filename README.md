# Kairo 🤖

**A personal AI assistant built with Python, Streamlit, and AI models.**

Kairo is a personal AI assistant project designed to run on a Windows laptop. It brings together AI conversations, local memory, chat history, and learning features in one interface.

The goal is to build an assistant that can become more useful over time while keeping personal data under the user's control.

## Features

- **AI conversations:** Chat with different AI models.
- **Multiple model support:** Connect to local models through Ollama and cloud-based models.
- **Chat history:** Save and revisit previous conversations.
- **Separate user histories:** Keep conversations organized by user.
- **Local memory:** Store selected information locally using SQLite.
- **Learning system:** Save corrections and lessons to help improve future responses.
- **Thinking indicators and timers:** Track response activity.
- **Model selection:** Choose which AI model handles a conversation.

## Technology

Kairo is built using:

- Python
- Streamlit
- Ollama
- SQLite
- Gemini API integration

## Requirements

Before running Kairo, you will need:

- Windows, macOS, or Linux
- Python
- Git
- Ollama (for local AI models)
- The required Python packages
- API credentials for any cloud AI services you choose to use

## Getting Started

1. Download or clone this repository.
2. Install Python and the required dependencies.
3. Install Ollama if you want to use local AI models.
4. Configure any required API credentials.
5. Run the Streamlit application.

Detailed installation instructions and the dependency list will be added as the project is prepared for public use.

## Privacy

Kairo is designed with personal data ownership in mind.

Local conversation history and memory should remain on the user's device unless the user deliberately configures an external service or integration.

**Never upload personal databases, API keys, passwords, or private configuration files to this repository.**

## Project Status

Kairo is actively being developed. Features, integrations, and documentation may change as development continues.
